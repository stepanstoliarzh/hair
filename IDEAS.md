- [x] Онлайн-версия: аккаунты, общий каталог, одна оценка на человека, админ.
- [x] Перенос причесок и старых оценок из резервной копии локальной версии.
- [x] Автотесты (`tests/run.sh`) и правила для автоулучшений (`CLAUDE.md`).
- [x] Поделиться ссылкой: кнопка «Ссылка» рядом с «Картинка» на странице прически.
- [x] Аккаунт владельца прически: статус выдаётся в базе (колонка `hairstyles.wearer`), прически

- [x] Лайк владельца: лайки на рецензиях (таблица `review_likes`), лайк владельца прически
  помечен «Нравится владельцу прически».
- [x] Новое с прошлого визита: метка «Новое» на прическах и оценках, появившихся после прошлого
  захода, «+N новых» на карточке и число новых в ленте.
- [x] Иконка сайта и превью ссылки: чёрно-белая иконка «H» (вкладка, экран «Домой» на iPhone),
  картинка-превью 1200×630 и Open Graph-теги для мессенджеров.
- [x] Смена ника: кнопка «Сменить ник» в своём профиле, проверка занятости и формата,
  оценки и прически остаются за участником.
- [x] «Показать ещё»: каталог показывает по 24 прически, лента — по 30 оценок, кнопка
  «Показать ещё» и «Показано N из M»; поиск, теги, сортировка и фильтр ленты начинают список заново.
- [x] Статистика: раздел «Статистика» в меню — сводка (прически, оценки, участники, средний балл),
  распределение оценок по вердиктам, самые активные участники, самые спорные образы.
