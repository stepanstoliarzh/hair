# HairRate — онлайн-версия с регистрацией

Общий каталог причесок: участники регистрируются, добавляют прически и оценивают их по формуле 4–67.
Данные, аккаунты и фото хранятся в Supabase, сам сайт — обычные статические файлы (подходит GitHub Pages).

## Файлы

- `index.html`, `style.css`, `script.js` — сайт.
- `config.js` — адрес проекта Supabase и публичный ключ. **Единственный файл, который нужно править.**
- `supabase/setup.sql` — схема базы: таблицы, правила доступа, хранилище фото. Запускается в Supabase → SQL Editor; повторный запуск безопасен.
- `tests/` — автотесты (см. ниже).
- `CLAUDE.md` — правила для Claude, `IDEAS.md` — очередь улучшений, `CHANGELOG.md` — журнал изменений.

## Как устроено

- **Регистрация** по нику, почте и паролю. Ник уникален без учёта регистра, почту другие участники не видят.
- **Смотреть каталог могут все**, добавлять прически и ставить оценки — только после входа.
- **Одна оценка от человека на прическу.** Её можно изменить (появится пометка «изменено») или удалить.
- **Балл считает база** по той же формуле, что и сайт (проверено на всех 7290 комбинациях), поэтому подделать его нельзя.
- **Править** можно только свои прически и оценки. **Удалять** — свои; админ может удалять любые.
- **Фото** загружаются в хранилище Supabase, каждый участник — только в свою папку. Перед загрузкой сжимаются до 1400 px.
- **Перенос из старой версии:** после входа внизу страницы есть «Перенести прически из резервной копии». Прически переносятся от вашего имени; из оценок переносятся только поставленные под вашим ником.
- Сессия хранится в браузере и обновляется автоматически.
- Клиент к Supabase написан на `fetch`, внешних библиотек нет.

## Как сделать себя админом

После регистрации на сайте откройте Supabase → SQL Editor и выполните (подставьте свой ник):

```sql
update public.profiles set is_admin = true where username = 'ВАШ_НИК';
```

## Выкладка на GitHub Pages

1. Создайте публичный репозиторий, например `hairrate`.
2. Загрузите в него `index.html`, `style.css`, `script.js`, `config.js` (кнопка «uploading an existing file»).
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/hairrate/`.

Чтобы обновить сайт, загрузите новые версии файлов в тот же репозиторий.

## Автотесты

```bash
bash tests/run.sh
```

Скрипт поднимает локальную копию Supabase (Postgres + PostgREST + шлюз входа и фото), применяет
`supabase/setup.sql`, сверяет формулу сайта и базы на всех 7290 комбинациях и прогоняет сайт в браузере:
регистрация, добавление, оценки, права участников и админа, перенос старой копии, вёрстка на телефоне.
Нужны PostgreSQL, Node.js, Python 3 и Playwright с Chromium.

## Автоулучшения

Раз в 3 дня Claude берёт задачу из `IDEAS.md`, делает её, прогоняет тесты и открывает pull request.
Чтобы изменение попало на сайт, примите PR на GitHub (кнопка «Merge»). Свои пожелания дописывайте
в раздел «От владельца» в `IDEAS.md`. Через коннектор Supabase Claude может добавлять в базу новые
таблицы и колонки, но не может удалять или менять данные участников (правила — в `CLAUDE.md`).

## Если что-то не работает

- **«Не удалось загрузить каталог»** — проект Supabase на бесплатном тарифе засыпает после недели без посещений. Откройте панель Supabase и нажмите «Restore project».
- **«Сайт ещё не подключён к базе»** — проверьте адрес и ключ в `config.js`.
- **«Почта не подтверждена»** — в Supabase: Authentication → Sign In / Providers → Email → выключите «Confirm email».
